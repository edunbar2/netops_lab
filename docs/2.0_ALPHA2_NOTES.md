# GNS3 CCNP Labs 2.0.0-beta2

This release begins the 2.0 GUI transition. It is not the final 2.0 feature-complete release.

## What changed

- PySide6/Qt is now the primary GUI development target.
- Tk/ttkbootstrap remains available as a legacy fallback.
- The generated-lab structure from 1.9 remains intact: metadata, topology map, hints, generation summary, answer keys, starter configs, and blank-topology output.
- The installer and launch scripts now prefer the Qt GUI unless the legacy Tk GUI is explicitly requested.

## What is still ahead for 2.0

- Guided Learning Mode.
- Student / Instructor / Explorer modes.
- Richer Markdown rendering.
- Side-by-side config comparison.
- More detailed deployment status reporting.
- Formal audit/validation report views.
- Installer check/repair mode.

## Launch commands

Qt beta GUI:

```bash
python3 gns3_ccnp_lab_gui_qt.py
```

Legacy Tk GUI:

```bash
python3 gns3_ccnp_lab_gui.py
```

Installer with Qt launch:

```bash
python3 install.py --launch-gui
```

Installer with legacy Tk launch:

```bash
python3 install.py --launch-gui --legacy-tk
```
