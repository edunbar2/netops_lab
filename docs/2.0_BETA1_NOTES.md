# GNS3 CCNP Labs 2.0.0-beta2

2.0.0-beta2 is the first beta release for the 2.0 GUI transition. The PySide6/Qt GUI is now the default interface for testing and future feature work. The legacy Tk GUI remains packaged as a fallback while the beta line stabilizes.

## Beta-ready areas

- Scenario browsing with Exam, Deployment, Domain, Topic, Difficulty, Type, and Search filters.
- Lab readiness checks.
- Lab generation using the existing generator backend.
- Generation controls for project name, host type, start nodes, Cisco config push, endpoint config push, and verification collection.
- Lab Workspace document viewing with answer-key reveal confirmation.
- Starter/answer-key/blank config viewing.
- Side-by-side starter versus answer-key config comparison.
- Topology map table view.
- Blank topology generation under Advanced Tools.
- Offline lab audit launch under Advanced Tools.
- Persistent Settings page for server, output directory, theme, host type, push defaults, verification, endpoint credentials, and timeouts.

## Still planned for later beta builds or 2.0 final

- Full Guided Learning Mode with persistent progress state.
- Student / Instructor / Explorer modes.
- Highlighted config diffs instead of side-by-side viewing only.
- Better markdown rendering and document search.
- Formal audit report viewer with pass/warn/fail rows.
- Open generated project in GNS3 Web UI.
- Installer `--check` and `--repair` workflows.
- Wider scenario-aware learning metadata enrichment.

## Legacy Tk fallback

```bash
python3 gns3_ccnp_lab_gui.py
```

Or through the installer:

```bash
python3 install.py --launch-gui --legacy-tk
```
