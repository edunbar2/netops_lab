# GNS3 CCNP Labs 2.0.0-beta2.1

2.0.0-beta2.1 is the guided-learning and workflow beta. It builds on the Qt GUI transition from beta1 and starts implementing the broader 2.0 usability roadmap.

## Highlights

- Added Student, Explorer, and Instructor learning modes in the Qt Lab Workspace.
- Added a Guided Learning tab with progressive hint reveal.
- Answer-key reveal behavior now respects the selected learning mode.
- Added a highlighted HTML diff preview for starter versus answer-key configs.
- Added generated `validation_report.md` for scenario labs and blank topology output.
- Blank topology output now includes `metadata.json`, `topology_map.md`, `generation_summary.md`, and `validation_report.md`.
- Added installer `--check` and `--repair` modes.

## Scope Notes

This is still a beta. The guided workflow is intentionally local/read-only: it does not yet connect to live router consoles, grade device state, or persist learner progress across sessions. Those are candidates for later 2.0.x or 2.1 work.
