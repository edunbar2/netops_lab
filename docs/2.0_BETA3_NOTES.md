# GNS3 CCNP Labs 2.0.0

Beta3 is a stabilization and workflow-polish release for the Qt/PySide6 2.0 line.

## Focus

- Preserve the beta2 guided-learning workflow.
- Add persistent, local guided-learning progress for each generated lab.
- Make validation and generation reports easier to view inside the Lab Workspace.
- Continue treating the legacy Tk GUI as a fallback while Qt remains the primary 2.0 GUI.

## Guided progress

When a lab is loaded in the Qt Lab Workspace, guided-learning mode, revealed hints, and locally completed steps are saved in `.guided_progress.json` inside that generated lab folder. This is intentionally local to the lab output and does not require accounts or external state.

## Reports tab

The Lab Workspace now includes a Reports tab that surfaces:

- `validation_report.md`
- `generation_summary.md`
- `metadata.json`

This is intended to make generation/deployment clarity more visible before the final 2.0 stable release.
