# GNS3 CCNP Labs 2.0.0

This stable release stabilizes the Qt/PySide6 2.0 line after beta3. It does not introduce a new major workflow; it focuses on release readiness, startup safety, documentation cleanup, and UI polish.

## Included fixes

- Fixed the Qt highlight/selection color behavior so selected text and selected rows use theme-aware colors instead of a hardcoded dark blue accent.
- Added stronger selection styling for text edits, plain text edits, combo/list/table views, and item selections.
- Updated the package version and release notes for the Final line.
- Kept the legacy Tk GUI available as a fallback while the Qt GUI remains the default 2.0 path.

## Validation target

Final should be tested by launching the Qt GUI, generating a lab, opening the Lab Workspace, using Guided Learning, viewing configs, viewing reports, and generating a blank topology. If no blocking bugs are found, the next release can be 2.0.0 final.
