# GNS3 CCNP Labs 2.0.0

GNS3 CCNP Labs 2.0.0 promotes the PySide6/Qt interface to the primary GUI and keeps the legacy Tk/ttkbootstrap GUI available as a fallback.

## Highlights

- Qt-first desktop GUI for the 2.0 line.
- Lab Workspace with document viewing, topology map table, config viewing, and starter-vs-answer config comparison.
- Guided Learning workflow with Student, Explorer, and Instructor modes.
- Progressive hint reveal and per-lab guided progress state.
- Generated lab metadata, topology map, generation summary, hints, and validation report artifacts.
- Advanced Tools area for blank topology generation and offline lab audit.
- Exam-first scenario filtering with deployment mode, domain, topic, difficulty, type, and search.
- Theme-aware Qt highlight/selection colors.
- Legacy Tk GUI retained for fallback testing.

## Recommended launcher

```bash
python3 gns3_ccnp_lab_gui_qt.py
```

The legacy GUI remains available:

```bash
python3 gns3_ccnp_lab_gui.py
```

## Upgrade note

This release is functionally based on the 2.0 release-candidate line. No large features were added after the release candidate; the final package focuses on versioning, documentation, and release stabilization.
