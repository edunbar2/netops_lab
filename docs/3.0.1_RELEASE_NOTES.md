# GNS3 CCNP Labs 3.0.1

3.0.1 is a stability patch for the 3.0.0 release.

## Fixes

- Retains Qt worker threads until they fully finish so the GUI does not exit with `QThread: Destroyed while thread is still running`.
- Tracks generator, lifecycle, server project manager, and console workers through a common cleanup path.
- Adds close-time cleanup for active console and background workers.

## Versioning

- Returns release labels to major/minor/patch semantic versions.
- Future patch builds should use `3.0.x`; larger compatible feature releases should use `3.1.x`.
