# GNS3 CCNP Labs 3.0.2 Release Notes

3.0.2 is a launcher reliability patch for macOS and Linux.

## Fixed

- Reworked the default Qt GUI launchers for macOS and Linux so they resolve the application directory from the launcher location instead of relying on the terminal's current working directory.
- The launchers now prefer a local `.venv/bin/python` when present, then fall back to `python3` or `python`.
- The launchers now check for Python and PySide6 before starting the application and print actionable dependency guidance when either is missing.
- macOS `.command` launchers now keep the terminal window open on errors so users can see the failure message.
- Legacy Tk launcher scripts received the same application-directory and Python-resolution handling.
- Unix executable permissions are set on the macOS and Linux launcher scripts in the release archive.

## Versioning

This release continues the plain major/minor/patch versioning scheme. The previous 3.0.1 patch remains the thread-lifecycle stability release; 3.0.2 is focused on launcher behavior only.
