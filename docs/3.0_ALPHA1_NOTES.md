# GNS3 CCNP Labs 3.0.0-alpha1 Notes

This alpha starts the transition from a lab generator with a viewer into an integrated practice workspace.

## Implemented

- Structured per-lab workspace content in `content/*.json`.
- Schema-3.0 `lab_manifest.json` for generated scenario labs.
- Slimmer `student_brief.md` focused on the learner-facing story, symptoms, context, requirements, and expected outcome.
- `project_info.md` and `content/project_info.json` for metadata that previously cluttered the student brief.
- Explicit guided-practice steps in `content/guided_steps.json` and `guided_practice.md`.
- Structured hints in `content/hints.json`, with `hints.md` preserved as an export.
- `topology.json` groundwork for the future graphical topology view.
- Configs duplicated into `configs/initial/` and `configs/answer_key/` while legacy `starter_configs/` and `answer_key_configs/` remain.
- Qt config viewer now preserves the selected device when switching between Initial and Answer Key where the same file exists.

## Still Planned for Later 3.0 Builds

- Graphical topology visualization.
- Integrated Telnet console sessions.
- Deploy/practice/reset/delete lifecycle controls.
- Full guided-practice redesign tied to live device interaction.
