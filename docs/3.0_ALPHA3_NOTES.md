# 3.0.0-alpha3 Notes

This alpha moves the 3.0 line into the integrated-console phase.

## Included

- A new **Consoles** tab in the Qt Lab Workspace.
- Console sessions sourced from generated lab deployment metadata (`metadata.json` / `lab_manifest.json`).
- Basic multi-tab console support.
- Basic send, send+enter, reconnect, and close-console actions.
- The `twilight_parchment` theme remains available as a dark-academia companion to `parchment`.

## Still to come

- Richer terminal emulation / ANSI handling.
- Click-through from topology nodes directly into console tabs.
- Deploy, reset, and delete lifecycle controls.
- Deeper guided-practice redesign tied to live practice workflow.
