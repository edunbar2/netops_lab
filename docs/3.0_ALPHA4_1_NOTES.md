# 3.0.0-alpha4.1 Notes

This is a stabilization patch for the alpha4 lifecycle build.

## Fixed

- Replaced the invalid `QGraphicsScene.addRoundedRect` call with Qt's supported `addRoundRect` API.
- Made `load_workspace()` tolerate optional-pane failures so topology issues no longer prevent the workspace, guided view, reports, lifecycle status, or consoles from loading.
- Improved theme-aware highlight/selection colors for light themes and `twilight_parchment`.
- Ensured the Guided Learning tab renders useful starting content immediately when a lab is loaded.
- Improved console endpoint discovery by falling back to the configured GNS3 server host when `console_host` is missing or unusable.

## Still in alpha scope

The integrated console remains a basic Telnet session view. Full terminal emulation, topology click-to-console, and practice lifecycle polish are still planned for later 3.0 builds.
