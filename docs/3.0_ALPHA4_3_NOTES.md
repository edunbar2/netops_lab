# 3.0.0-alpha4.3 Notes

This hotfix stabilizes the 3.0 alpha4 workspace.

## Fixed

- Topology visualization did not appear even though the topology table loaded. The GUI now normalizes topology data and renders visible device/link graphics using supported Qt scene items.
- Custom themes reused the same tertiary color for selection highlights, table headers, group borders, and tab accents. The Qt GUI now applies separate theme roles for selection, headers, borders, and titles.
- The Generate page was cramped on macOS. Filters now use a two-row grid, the scenario table receives more space, and the details pane is constrained.

## Preserved

- Integrated console groundwork from alpha3/alpha4.
- Lifecycle controls from alpha4.
- Structured content/workspace model from alpha1.
