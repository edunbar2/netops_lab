# 3.0.0-alpha4.4 Notes

This is a small UI polish release on the alpha4 lifecycle/consoles line.

## Fixed

- Generate-tab action buttons in the right-side details pane are now shorter and arranged in a compact grid.
- The topology visualization background now follows the active theme instead of using a fixed dark canvas.
- Topology links now use theme-aware, higher-contrast line colors and thicker strokes.
- The topology detail pane now reports how many topology links were rendered, which should make it easier to distinguish data issues from visibility issues.
