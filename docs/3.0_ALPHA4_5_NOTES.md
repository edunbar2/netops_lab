# 3.0.0-alpha4.5 Notes

This is a focused UI stabilization pass after alpha4.4.

## Fixed

- The Generate tab right panel now keeps full button labels while giving scenario details and command output more usable space.
- The topology visualization no longer borrows theme tertiary colors for its canvas. It uses a neutral medium-gray canvas intended to be readable without being bright.
- Topology links are normalized from the generated topology data and drawn with stronger contrast.

## Not changed

- Console connectivity and lifecycle controls are unchanged from alpha4.x.
- Full topology interaction remains planned for a later 3.0 milestone.
