# 3.0.0-alpha4 Notes

This alpha adds the first lab lifecycle controls to the Qt Lab Workspace.

## Included

- New Lifecycle tab in the Lab Workspace.
- Refresh deployment status for the loaded GNS3 project.
- Start nodes, stop nodes, and reset nodes from inside the application.
- Delete the deployed GNS3 project when done while preserving local generated files.
- Lifecycle status pane that uses generated lab deployment metadata.

## Notes

Lifecycle actions require a generated/deployed lab with a GNS3 project ID in `metadata.json` or `lab_manifest.json` and a reachable configured GNS3 server.

## Still to come

- Stronger practice-session state.
- Guided-practice redesign around explicit phases.
- Better integration between topology nodes, console tabs, and lifecycle status.
