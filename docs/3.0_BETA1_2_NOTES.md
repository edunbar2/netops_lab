# 3.0.0-beta1.2 Notes

This beta polish release begins the topology visualization remake using bundled GNS3 symbols.

## Included

- Bundled GNS3 symbols in `assets/symbols/`.
- Symbol-based device rendering in the Qt topology view.
- Shape fallback rendering for device types without matching symbols.
- Link attachment to node edges instead of node centers.
- Offset link labels to reduce overlap.

## Notes

The topology table remains the source-of-truth view for exact interface and adapter/port mappings. The visual topology is intended to become increasingly interactive through later 3.0 releases.
