# 3.0.0-beta1.3 Notes

This update improves topology label readability.

## Included

- Short interface labels in the graphical topology view.
- Full interface names retained in the topology table and link detail pane.
- Support for common Cisco-style names such as Ethernet, FastEthernet, GigabitEthernet, TenGigabitEthernet, Serial, Loopback, Port-channel, VLAN, and management interfaces.
