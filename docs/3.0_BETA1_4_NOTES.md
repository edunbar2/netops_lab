# 3.0.0-beta1.4 Notes

This build improves topology symbol handling.

## Included

- Additional GNS3 symbols bundled in `assets/symbols/`.
- Classic GNS3 symbols are now the default topology icons.
- Settings includes **Choose Topology Symbols…** for mapping device roles to icons:
  - Router
  - Switch
  - PC / Endpoint
  - Firewall
  - Cloud / ISP
  - Unknown / Fallback
- The renderer still falls back to simple drawn shapes when an icon is missing.
