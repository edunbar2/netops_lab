# 3.0.0-beta1 Notes

This beta begins the guided-practice redesign. The Qt Lab Workspace now treats guided learning as an explicit step-based workflow instead of a single document view.

## Included

- Step list with completion state.
- Previous/next step navigation.
- Dedicated current-step reading pane.
- Dedicated hints pane.
- Progressive hint reveal in Student mode.
- Copy Suggested Commands button.
- Mark Step Complete now completes the selected step and advances through the practice flow.

## Still to come

- Step-specific console shortcuts.
- Step-specific topology highlighting.
- Practice session notes and summary.
- Deeper lifecycle integration into Start Practice / End Practice flows.
