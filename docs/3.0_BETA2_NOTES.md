# 3.0.0-beta2 Notes

This beta focuses on practice workflow polish.

## Included

- A new Practice tab in the Qt Lab Workspace.
- Start Practice and End Practice actions.
- Per-lab `practice_state.json`.
- Persistent `student_notes.md`.
- End-of-session `practice_summary.md`.
- Quick navigation to Guided Learning, Topology, Consoles, and Lifecycle.
- Guided Practice shortcut buttons for Consoles and Topology.

## Deferred to beta3

Beta3 should focus on the actual guided-lab instructional content: what each guided step should say, how much command guidance to provide, how hints should be structured, and how mentor-style content should be split across scenario/context/requirements/hints/answer-key sections.
