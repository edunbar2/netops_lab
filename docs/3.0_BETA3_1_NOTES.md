# 3.0.0-beta3.1 Notes

This is a narrow terminal-noise hotfix for beta3.

## Fixed

- Suppressed the known harmless Qt warning:

```text
QTextCursor::setPosition: Position '1' out of range
```

This warning can be emitted internally by Qt when Markdown/text panes are refreshed and a previous cursor position no longer exists in the new document. The warning does not indicate lab-generation, workspace, console, or topology failure.

Other Qt messages are still emitted to stderr.
