# 3.0.0-beta3.2 Notes

This hotfix extends the beta3 readability work to content rendered inside the Qt app.

## Fixed

- Structured JSON-backed Documents sections now render with more whitespace.
- Guided Practice step content now has clearer spacing between sections.
- Qt text panes now use document-level spacing styles so headings, paragraphs, and lists are easier to read.

The exported Markdown files already had the beta3 whitespace improvements; this release applies the same principle to app-rendered content.
