# 3.0.0-beta3.3 Notes

This hotfix tightens learner-facing content and the Generate Lab table.

## Included

- Student-facing symptom text now strips common causal/root-cause clauses such as `because`, `due to`, and `caused by`.
- Answer keys still retain the full root-cause explanation.
- The Generate Lab table now starts with the scenario title and moves the backend ID to the final column.
- Scenario details no longer lead with the backend scenario ID.
