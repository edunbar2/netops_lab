# 3.0.0-beta3 Notes

This beta focuses on guided-lab content quality.

## Included

- User-facing symptom framing instead of answer-revealing symptom text.
- More readable student briefs with additional whitespace between sections.
- Topic-aware guided practice templates.
- Guided steps with objective, instructions, what-to-look-for guidance, suggested commands, and completion criteria.
- Expanded answer keys that explain root cause, symptom chain, proof, correction, common wrong fixes, and verification.
- `scripts/audit_guided_content.py` for checking generated guided-content structure.

## Intent

When a student opens the answer key, it should function like a complete mentor explanation rather than a terse command correction.
