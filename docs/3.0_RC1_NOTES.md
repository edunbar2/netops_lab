# 3.0.0-rc1 Notes

This release candidate is intended for final validation before 3.0.0.

## Included

- Qt-based integrated practice workspace.
- Structured generated lab content and readable workspace sections.
- Guided Practice with visible steps, hints, suggested commands, and progress.
- Topology visualization with selectable bundled GNS3 symbols.
- Integrated Telnet console groundwork.
- Lab lifecycle controls for start/stop/reset/delete project workflows.
- Practice state, student notes, and practice summaries.
- Improved guided content quality and answer-key explanations.
- Student-facing symptoms that avoid revealing the root cause directly.
- Scenario IDs de-emphasized in learner-facing lab browsing.

## Validation focus

Before final 3.0.0, test:

1. Install and launch on Windows/macOS/Linux.
2. Generate and deploy several labs across routing, switching, services, and automation topics.
3. Confirm the Lab Workspace loads automatically after generation.
4. Confirm topology icons, links, and labels render correctly.
5. Confirm console endpoints populate and connect when GNS3 provides console metadata.
6. Confirm lifecycle start/stop/reset/delete actions behave safely.
7. Confirm guided steps, hints, student brief, observed symptoms, and answer keys are readable and correctly scoped.
