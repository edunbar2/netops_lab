# 3.0.0-rc2 Notes

3.0.0-rc2 adds server-level GNS3 project management so users do not need to log into the GNS3 web UI or server shell to reconnect to existing projects or clean up stale labs.

## New: GNS3 Projects page

The Qt GUI now includes a top-level **GNS3 Projects** page.

It can:

- list projects from the configured GNS3 server;
- show project name, status, node count, running-node count, generated-lab match, project ID, and update timestamp when provided by the API;
- filter by all projects, likely app-generated projects, running projects, or stopped projects;
- start nodes for selected projects;
- stop nodes for selected projects;
- delete selected projects after a confirmation dialog.

## External project workspaces

When a server project was not generated by GNS3 CCNP Labs, the app creates a lightweight local workspace under:

```text
generated_labs/external_gns3_projects/
```

External workspaces include the server/project ID and discovered node console metadata. Guided practice, answer keys, and generated configuration sets are intentionally unavailable unless the project has local generated-lab metadata.

## Safety behavior

Deleting projects from the GNS3 Projects page removes the project from the GNS3 server only. It does not delete local generated lab folders.
