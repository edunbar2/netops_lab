# 3.0.0 Release Notes

3.0.0 is the stable release of the integrated GNS3 CCNP Labs practice application.

## Highlights

- Integrated practice workspace with guided practice, lab documents, lifecycle controls, topology details, console access, notes, summaries, and reports.
- Server-level GNS3 Projects page for discovering, connecting to, stopping, starting, and deleting projects already present on the configured GNS3 server.
- External-project mode for GNS3 projects that were not generated by this app. Guided content is unavailable for those projects, but lifecycle controls and console endpoints remain available when exposed by GNS3.
- Generated-project cleanup workflow for administrators, including selected-project deletion and generated-project bulk deletion with explicit confirmation.
- Learner-facing symptom text avoids giving away the root cause, while answer keys retain the complete explanation.
- Generated lab documents and app-rendered structured content use improved spacing for readability.
- Final UI polish for the GNS3 Projects filter row so the Show label and dropdown appear as a clean compact control group.

## Upgrade note

Deleting a project from the GNS3 Projects page removes it from the configured GNS3 server only. Local generated lab folders are not deleted.
