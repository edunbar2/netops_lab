# NetOps Labs 4.0.0 Release Notes

NetOps Labs 4.0.0 is the identity and catalog-foundation release.

## Major changes

- The application is now presented as **NetOps Labs**.
- New subtitle: **Hands-on infrastructure training for networking, Linux, and security.**
- The lab catalog is now organized primarily around **study paths** instead of exams.
- Exams such as CCNA and CCNP ENCOR remain available as secondary alignment metadata.
- Existing GNS3 CCNP Labs 3.x generated labs remain compatible.

## Initial study path model

The bundled catalog now supports:

- CCNA Foundations
- CCNP Enterprise
- Secure Enclave Networking
- RHEL9 Operations
- Network Troubleshooting

The existing bundled scenarios are mapped into study paths using explicit metadata where available and compatibility mappings where older 3.x metadata is present.

## Lab type model

Lab types remain first-class catalog metadata and are used as filters:

- Build
- Troubleshoot
- Verify
- Mixed
- Hardening
- Explore

## Compatibility

Internal module and launcher names are intentionally kept compatible in this release. This avoids breaking existing scripts, local generated labs, and 3.x workspace metadata during the transition from GNS3 CCNP Labs to NetOps Labs.
