# 4.0.1 Release Notes

4.0.1 is a stabilization patch for the NetOps Labs 4.0 transition.

## Highlights

- Adds GitHub branch, pull request, merge, and unit-test guardrails for future patch, minor, and major releases.
- Adds a GitHub Actions unit-test workflow for pull requests targeting `main`.
- Streams lab generation output live in the Qt GUI so users can see what the generator is doing while GNS3 projects are created.
- Adds explicit generation progress stages for planning, template checks, node creation, link creation, metadata refresh, file writing, node startup, config push, endpoint push, and verification.
- Reuses a shared HTTP session for GNS3 API calls, reducing repeated connection setup overhead.
- Skips redundant node-detail API calls when GNS3 already returns console metadata during node creation.

## Verification

- `python -m unittest discover -s tests`
- `python -m py_compile gns3_ccnp_lab_generator.py gns3_ccnp_lab_gui_qt.py`
